# ТАМЫР — 5-шаблон

Қазақ мәдениетіне арналған көрнекі хикая. Барлық бет мәтіні қазақша, кирилл әліпбиімен жазылған. Негізгі әрекет — парақты айналдыру: көріністерді ашу үшін батырмалар мен модаль терезелер қажет емес.

## Іске қосу

```sh
pnpm install
pnpm dev          # http://localhost:5176
pnpm build
pnpm lint
pnpm test         # Мәтін, құрылым және файл сілтемелері
pnpm test:browser # Браузердегі анимация сынақтары
```

Браузер сынақтарына Chromium қажет: `pnpm exec playwright install chromium`.

## Көріністер

- **Бастау:** көлемді алтын қошқармүйіз айналып, төрт бөлікке ашылады; ірі әріптер біртіндеп тарайды.
- **Дала:** шағын терезедегі панорама толық экранға жайылады; тақырыптар кезекпен ашылады.
- **Өрнек:** біртіндеп сызылатын сегіз иірім тұтас оюға бірігеді. Мәтіндер үш кезеңмен ауысады.
- **Мұра:** сырмақ, домбыра және шаңырақ көріністері. Үлкен экранда көлденең қозғалыс, телефонда тік тізбек қолданылады.
- **Жалғастық:** қарама-қарсы бағытта жылжитын ірі мәтін мен оюлы жолақтар.
- **Шаңырақ:** шеңберлер, 64 уық және күлдіреуіштер ретімен сызылып, ортақ бейнеге жиналады.
- **Қорытынды:** ірі әріптер мен ою арқылы хикая түйінделеді.

Анимациялар айналдыру орнына байланысты және кері айналдырғанда кері орындалады. Қозғалысты азайту параметрі қосылса, бекітілген көріністер мен анимациялар өшіп, мазмұн ашық қалады. WebGL қолжетімсіз болса, алтын мүсіннің орнына векторлық ою көрсетіледі.

## Негізгі файлдар

| Файл | Мақсаты |
| --- | --- |
| `src/App.tsx` | Мәтіндер мен бөлімдер |
| `src/lib/useJourney.ts` | Айналдыру анимациялары |
| `src/components/GoldenOrnament.tsx` | Көлемді алтын ою |
| `src/components/Ornament.tsx` | Векторлық ұлттық өрнектер |
| `src/components/Shanyraq.tsx` | Шаңырақ сызбасы |
| `src/components/Dombra.tsx` | Домбыра бейнесі |
| `src/index.css` | Түстер, қаріптер, өлшемдер |

Қошқармүйіз, домбыра және шаңырақ — осы жобаға арнайы жасалған заманауи көркем бейнелер. Панорама нақты тарихи оқиғаның деректі суреті емес. Оюдың мәдени негізі туралы: [Kazakh felt traditions](https://crees.ku.edu/kazakh-felt).

Қаріптер мен суреттер жоба ішінде сақталады. Noto Sans Display және Noto Serif қаріптерінің қазақ әліпбиіндегі барлық арнайы әріпті қолдайтыны тексерілген. Қаріп лицензиялары `public/fonts/` ішінде.

## Дала бейнесі

## Тексеру нәтижесі

Өндірістік жинақтау, ESLint және серверде көрсетілген HTML мазмұнының тексерулері өтті. Тексерулер кирилл мәтінін, қолжетімділік белгілерін, сілтемелерді, бірегей идентификаторларды, жергілікті файлдарды және басуды қажет етпейтін құрылымды қамтиды.

Осы жұмыс ортасында Chromium іске қосылуы `spawn EPERM` қатесімен бұғатталды. Сондықтан браузердегі анимация және визуалды тексерулер өткен деп белгіленбейді. Оларды рұқсаты бар ортада `pnpm test:browser` арқылы орындауға болады. `node tests/visual-review.mjs` көріністердің скриншоттарын `artifacts/` қалтасына сақтайды.
